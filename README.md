# A-Virtual-A.I.-Assistant-Desktop-ROBOT

It is a computer system that designed in such a way that typically requires interaction from human.
These assistant can help to reduce human effort and the consumes time while performing any task
It removed the concept of typing completely and behave as another individual to whom we are talking and asking to perform many task.
##  Aim:
 These project is take the command as input through microphone of
     user and returns the output as string.

In Python there is an API called SpeechRecognition which allows us to the convert speech into text.

This output string is recognizing by this ROBOT  and perform all the necessary task execution definition like sendEmail(), Covid informtion, NASA information and many conditions in if condition like “open google”, “open Powershell”, “search on Wikipedia”, ”shows date, time, temperature, jokes” and “take screen shots” etc.
